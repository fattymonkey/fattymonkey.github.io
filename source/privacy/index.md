{% note primary %}
本协议说明本站收集、使用访客信息的规则，保护你的个人隐私。
{% endnote %}


# 一、信息收集范围
1. **主动提供信息**：在评论区自愿填写昵称、邮箱；邮箱仅用于评论回复通知，不会公开展示。
2. **自动采集信息**：浏览器型号、访问时间、页面、匿名访问日志，仅用于统计站点访问情况。
3. **不会主动收集**：真实姓名、身份证号、住址、银行卡等敏感隐私信息。


# 二、信息用途
1. 回复访客评论、沟通交流；
2. 统计站点访问热度，优化页面布局与内容；
3. 排查网站异常访问、爬虫攻击；


# 三、信息共享说明
1. 未经你明确同意，不会向第三方出售、出租你的个人信息；
2. 第三方服务（评论系统、访问统计）收集的数据，遵守第三方自身隐私政策；


# 四、数据保存期限
评论信息长期保存，你可联系站长申请删除自己发布的评论；
匿名访问日志定期清理，不作永久留存。


# 五、访客权利
你有权要求站长删除你发布的评论；可自行清理浏览器 Cookie 阻止非必要信息采集。


# 六、安全保障
站点采取合理技术手段保护数据，但无法绝对杜绝网络环境下的数据泄露风险，请谨慎主动提交敏感信息。


# 七、协议更新
本隐私协议可不定期更新，更新后发布于本页面，持续生效。
