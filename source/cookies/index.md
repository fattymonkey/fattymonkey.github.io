# 一、什么是 Cookie
Cookie 是网站发送至你浏览器并存储在设备上的小型文本文件，能够保存浏览状态、偏好设置，帮助网站识别回访访客，提升访问流畅度。


# 二、本站使用 Cookie 的目的
1. 记忆页面浏览设置、深色/浅色模式偏好；
2. 维持评论组件会话状态；
3. 统计站点基础访问数据，用于站点优化；
4. 区分新访客与回访访客，不用于追踪用户网络行为。


# 三、Cookie 分类
- **必要 Cookie**：保障网站基础功能正常运行，无法关闭；
- **功能性 Cookie**：保存你的界面偏好，可通过浏览器设置拒绝；
- **统计 Cookie**：匿名汇总访问数据，不会收集姓名、手机号等个人信息。


# 四、你如何管理 Cookie
你可以通过浏览器设置：阻止Cookie、清除已有Cookie、退出浏览器自动删除Cookie。
关闭 Cookie 可能导致评论系统、主题模式切换等功能异常。


# 五、第三方 Cookie
本站部分功能（评论系统、访问统计）可能由第三方服务写入Cookie，相关行为遵循对应服务商隐私条款。


# 六、政策更新
本站有权随时修订本 Cookie 政策，修订内容将直接在页面更新，不再单独通知。如有疑问，请通过页面评论或联系方式与站长沟通
